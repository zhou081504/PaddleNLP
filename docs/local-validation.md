## 原单文件稳态基线

已在 `PaddleNLP` 虚拟环境完成真实 CPU 推理、连续资源采样和功能回归。本记录是本机 demo 基线，不是正式业务的采购或并发承诺。

## 环境和测试条件

- CPU：Intel Core i7-12700H，20 个逻辑核；系统可见内存约 15.41 GiB。
- Python 3.10.21、Paddle GPU 包 3.3.1、PaddleNLP 3.0.0b4.post20260921、psutil 7.2.2。
- 实际使用 CPU，4 个推理线程，`uie-base`，姓名/地址/工作单位三个类别，阈值 0.5，最大模型序列长度 512。
- 外层批次 32 条，模型批次 8；初始化后预热一批，完整运行 3 轮，每轮均写脱敏结果。
- 样本为 `examples/demo.txt` 重复生成的 40 条合成文本，共 1,864 字符，无空行，平均每条 46.6 字符，最长 62 字符。正式计时总计 120 条；不代表长对话或真实业务分布。

复现命令（报告目录必须换成新目录）：

```bash
conda activate PaddleNLP
python examples/make_dataset.py --records 40 -o data/demo-40-new.txt
python -m benchmarks.run -i data/demo-40-new.txt --device cpu --threads 4 \
  --model-batch-size 8 --warmup 1 --repeats 3 --sample-interval 0.5 \
  --write-output --report-dir reports/cpu-demo-new
```

原始汇总为 `reports/local-cpu-demo-40/report.json`，时间线为同目录 `samples.csv`，脱敏结果为 `redacted.txt`。报告未记录原文或识别实体；这些运行产物不提交到 Git。

模型推理累计约 119.02 秒，几乎占据全部处理时间；这组样本的主要瓶颈在 UIE 推理。后续应在真实语料上分别测试模型批次、CPU 线程数、模型规格以及 GPU。现有数字不能说明 GPU 能加速多少，也不能按当前 20 个逻辑核无条件线性放大吞吐。

本次还验证了示例容量参数（100 万条、24 小时、预留 30%）：单工作进程约需 393.8 小时，线性模型算出 17 个并行工作进程。**这不是建议在本机启动 17 个进程**：每个进程约占 4 个逻辑核，还需各自加载模型；现有 CPU/内存无法据此承诺线性扩展。业务定容需换真实数据并实测目标并行数。
